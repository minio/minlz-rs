# cross_codec results

AMD Ryzen 9 9950X (16C / 32T, Zen 5), 64 GiB DDR5, Windows 11; Rust 1.92, release profile
(`lto = "thin"`, `codegen-units = 1`); snap 1.1.1, lz4_flex 0.11.6, flate2 1.1.9 (miniz_oxide),
zstd 0.13.3. MinLZ streams use 2 MiB blocks; SIMD blocks decode with AVX-512 on this CPU.
Best of 3 per codec and input. Single-threaded rows ran pinned to one CPU
(`start /affinity 10`), MT rows (32 threads) unpinned.

Generated with `cross_codec --report snappy.csv real.csv` from the CSV files in this directory.

The Snappy-set files decode as one block per stream, and every decode builds a new reader.
Whether its fresh buffers page-fault on first touch depends on the Windows heap state, so per-file
decode speeds on that set swing 2-4x between runs, for every codec. Over three runs the geomeans
moved by up to 17%.
